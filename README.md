# BMI Calculator using Python and NumPy

A simple BMI (Body Mass Index) Calculator built using Python and NumPy.

## 📌 About the Project

This project calculates a person's BMI using their weight and height.

The project uses the NumPy library for numerical calculation.

## 🧮 BMI Formula

BMI = Weight (kg) / Height² (m)

For example:

Weight = 65 kg

Height = 1.75 m

BMI = 65 / (1.75 × 1.75)

BMI ≈ 21.22

## 📊 BMI Categories

| BMI Range | Category |
|-----------|----------|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Normal Weight |
| 25 - 29.9 | Overweight |
| 30 or above | Obese |
